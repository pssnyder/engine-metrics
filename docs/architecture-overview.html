📋 Data Pipeline Flow

📦 Stage 1: Move (Local → Raw Bucket)

Source: Local tournament files (PGN, JSON, CSV)
Process: Automated file monitoring and transfer
Destination: Cloud Storage raw data buckets
Format: Preserves original file formats

📥 Stage 2: Ingest (Raw → Data Lake)

Source: Raw bucket files
Process: Cloud Dataflow ingestion pipelines
Destination: BigQuery raw tables
Format: Native structured format in BigQuery

🔄 Stage 3: Transform (Data Lake → Conformed)

Source: Raw BigQuery tables
Process: Data cleaning, validation, normalization
Destination: Conformed BigQuery datasets
Format: AI-ready, standardized schemas

📊 Stage 4: Report (Conformed → Analytics)

Source: Conformed datasets
Process: Aggregation, metrics calculation
Destination: Reporting tables and APIs
Format: Dashboard-ready metrics and features
