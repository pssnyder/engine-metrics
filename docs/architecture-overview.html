📋 Data Lakehouse Pipeline

📁 Layer 1: Raw Storage (Cloud Storage)

Volume: 4M puzzles (2GB), 50K+ games, 184 docs
Process: gsutil rsync from local repositories
Storage: gs://v7p3r-raw-data/ (lifecycle policies)
Format: PGN, SQLite, JSON, Markdown (native)

📊 Layer 2: Structured DB (BigQuery)

Source: Raw files in Cloud Storage
Process: Python ingestion scripts (parallel processing)
Tables: 12 core tables (partitioned, clustered)
Optimization: Partition by date, cluster by version

🔄 Layer 3: Analytics (dbt Models)

Source: BigQuery raw tables
Process: dbt SQL transformations (dims, facts, aggs)
Outputs: Materialized views, statistical UDFs
Quality: Automated tests, freshness checks

🤖 Layer 4: AI Serving (Agent Context)

Source: BigQuery analytics marts
Process: Scheduled queries → JSON exports
Storage: gs://v7p3r-agent-context/*.json
Consumption: Gemini API, Vector Search

⚙️ Layer 5: Stockfish Compute (Cloud Run)

API: FastAPI service (serverless)
Scaling: 0-10 instances (auto-scale)
Queue: Cloud Tasks (batch analysis)
Results: Ingest back to BigQuery

📈 Layer 6: Monitoring (Cloud Ops)

Dashboards: Data freshness, cost tracking
Alerts: SLA violations, pipeline failures
Logging: Centralized with severity filtering
Costs: Daily spend tracking, budget alerts
